# Improved Trader

Improved Trader is a gameplay mod for The Long Dark that tweaks some aspects of the trader mechanic.

## Features

### Trade Boxes

Sutherland has magically fixed his leg and can now deliver trade goods from newly placed trade boxes around Great Bear, including off the coast. They function identically to the box in Coastal Highway, except that each radio is tied to a box and can only deliver to that box.

### Locations 

* Quonset Gas Station Radio -> box at Misanthrope's Island (vanilla)
* Camp Office Radio -> along the tracks in the ravine transition zone
* Community Hall Radio -> Derelict cabins in Pleasant Valley
* Blackrock Barracks Radio -> Scenic view in Keeper's Pass South
* Cannery Trailer Radio -> Broken lighthouse
* Maintenance Shed Radio -> along the tracks in Forlorm Muskeg
* Milton Post Office Radio -> along the tracks in Forlorm Muskeg
* Vacant Depot Radio -> along the train cars in Far Range Branch Line

If you have an active trade initiated from one of these radios, it will always be present at the box associated with it. This is a limitation of how Hinterland designed the system for now. 

### Configurable Start

The settings feature an option to tweak the arrival day of the trader so it can arrive as soon or as late as you want. You can even start with the trader available on day 1. This will override the default setting of whatever difficulty you are playing, be aware. 

## Installation

* Install MelonLoader by downloading and running [MelonLoader.Installer.exe](https://github.com/HerpDerpinstine/MelonLoader/releases/latest/download/MelonLoader.Installer.exe)
* Install the following dependencies in your mods folder: 
  
- [ModSettings](https://github.com/DigitalzombieTLD/ModSettings/releases/latest)
- [ComplexLogger](https://github.com/Arkhorse/Complex-Logger/releases/latest)

* Install the latest release and drop it in your mods folder
